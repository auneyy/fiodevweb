PROSES MANAJEMEN USER

  • 1. Sinkronisasi: Ambil data user terbaru dari mesin absensi.
  • 2. Tambah User: Daftarkan identitas user baru di sistem manager.
  • 3. Sidik Jari: Input template sidik jari manual atau dari mesin.
  • 4. Foto Wajah: Upload foto untuk verifikasi pengenalan wajah.
  • 5. Register Online: Perintah mesin untuk memulai scan jarak jauh.
